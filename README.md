# Shipping Performance Dashboard (Tableau)

This Tableau dashboard analyzes delivery efficiency across the U.S.  
It includes metrics such as average shipping time by delivery type, state-level performance, and order count by delivery duration.

## Features
- Interactive filters: Order Date, Segment, Ship Mode
- Choropleth map of U.S. states
- Dynamic color scale for delivery speed
- Clear KPI segmentation by shipping type

## Tools Used
- Tableau Desktop
- Superstore dataset (sample data)
